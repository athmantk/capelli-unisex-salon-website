# 💇 Capelli Unisex Salon Website

A premium, modern, and responsive website designed for **Capelli Unisex Salon**, Mangaluru. The website provides visitors with an elegant way to explore the salon, view services and real photos, read customer reviews, and find the salon's location and contact information.

## ✨ Features

* 🏠 Modern and responsive homepage
* 💇‍♀️ Hair, beauty, makeup, nail, spa & grooming services
* 🖼️ Real salon photo gallery
* ⭐ Customer reviews section
* 📍 Google Maps location integration
* 📞 Direct call/contact button
* 📱 Fully responsive mobile design
* 🎨 Premium luxury-salon UI
* ✨ Smooth animations and transitions
* 🔍 SEO-friendly structure
* ⚡ Optimized for fast loading

* Read customer reviews
* Find the location

The website uses **real salon photographs** to showcase the interior, services, and overall salon experience.
